## 🌟 Tính Năng Nổi Bật

- 🛡️ **Auto cày tài nguyên cực nhanh**: Tự động tìm kiếm nhà hoang, nhà nhiều vàng/dầu theo cấu hình bạn đặt.
- 🧱 **Auto nâng cấp tường (Wall Upgrade)**: Tự động gom vàng/dầu dư thừa để nâng tường liên tục, tránh bị cướp.
- 🎯 **Thả quân thông minh theo kịch bản**: Hỗ trợ nhiều chiến thuật đánh (Barba-Archer, Gi-Wiz, E-Dragon, Goblin,...).
- 📱 **Hỗ trợ đa giả lập không giới hạn**: Kết nối siêu mượt với LDPlayer, BlueStacks, NoxPlayer, Memu qua ADB.
- 🔄 **Hệ thống Auto-Updater từ xa**: Tự động nhận diện và cập nhật phiên bản mới khi có update.
- ⚡ **Treo máy 24/7 ổn định**: Tự động kết nối lại khi mất mạng, duy trì online liên tục.

## 📥 Hướng Dẫn Cài Đặt

1. Tải bộ cài đặt `AutoClash_Setup.exe` từ trang web.
2. Nhấp đúp chuột vào file `AutoClash_Setup.exe` để mở trình cài đặt Wizard.
3. Chọn thư mục cài đặt và nhấn **Cài đặt ngay** (trình cài đặt sẽ tự cấu hình ADB, Tesseract OCR và tạo biểu tượng trên Desktop).
4. Mở AutoClash trên Desktop và thưởng thức!
